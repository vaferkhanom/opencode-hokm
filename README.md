حُکم — Telegram Mini App
========================

بازی ورق «حکم» به‌صورت مینی‌اپ تلگرام؛ تمام‌قانون، فارسی و راست‌به‌چپ، با فونت وزیرمتن و رابط کاربری شیشه‌ای-طلایی. کاملاً آفلاین در برابر هوش مصنوعی اجرا می‌شود؛ نیازی به سرور ندارد.

| | |
|---|---|
| حالت چهارنفره | یارگیری با آس، کوپ، پخش ۵–۴–۴، اعلام حکم با ۵ کارت اول، کوت و حاکم‌کوت (۲ و ۳ امتیاز)، چرخش حاکم/دیلر طبق قانون |
| حالت دونفره | پخش ۵+۵، دورریز ۳/۲، برگهٔ ۴۲تایی با قانون «نگه دار یا رد کن (دومی اجباری)» تا ۱۳ کارت، سپس دست‌ها |
| امتیاز | بردن دست = ۱ · کوت ۷–۰ = ۲ · حاکم‌کوت = ۳ · هدف بازی ۷ امتیاز |

ساختار
-------
```
index.html          شِل اپ (+ اسکریپت تلگرام و فونت وزیرمتن)
css/style.css       دیزاین‌سیستم، انیمیشن‌ها، RTL
js/cards.js         دادهٔ کارت، شافل سیددار، مرتب‌سازی
js/engine.js        موتور قانون (خالص، بدون DOM) — یارگیری، پخش، دست‌ها، امتیاز، چرخش نقش‌ها، فازهای دونفره
js/ai.js            مغز AI: انتخاب حکم، بازی کارت، دورریز، تصمیم برداشت
js/sound.js         افکت صوتی سینتی‌سایز‌شده (WebAudio، بدون فایل)
js/ui.js            ساخت DOM و انیمیشن‌ها (WAAPI)
js/app.js           چرخهٔ بازی، صفحه‌ها، اتصال تلگرام (Haptic، BackButton، تم، viewport)
tests/              تست موتور (۳۲۸ ادعا) + اسموک UI کامل با jsdom
```

اجرای محلی
----------
```bash
cd hokm-tma
python3 -m http.server 8080     # سپس http://localhost:8080
```
بیرون از تلگرام هم کار می‌کند (حالت دمو). تست‌ها:
```bash
npm install            # فقط jsdom برای تست UI
node tests/run-tests.js
node tests/smoke-ui.test.js
```

انتشار + اتصال به بات
---------------------
۱) پوشه را روی هر هاست استاتیک HTTPS منتشر کنید (GitHub Pages / Netlify / Vercel).
۲) در BotFather: `/newbot` یا بات خودتان → `/newapp` (یا Bot Settings › Menu Button) → آدرس `https://…/index.html` را بدهید.
۳) تمام.

نکتهٔ امنیتی: بازی تک‌نفره-آفلاین است و هیچ داده‌ای (از جمله initData) به سروری ارسال نمی‌شود؛ اگر بعداً بک‌اند افزودید، حتماً `initData` را سمت سرور با HMAC توکن بات اعتبارسنجی کنید.
