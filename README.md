حُکم — Telegram Mini App
========================

بازی ورق «حکم» به‌صورت مینی‌اپ تلگرام؛ تمام‌قانون، فارسی و راست‌به‌چپ، با فونت وزیرمتن و رابط کاربری شیشه‌ای-طلایی. کاملاً آفلاین در برابر هوش مصنوعی اجرا می‌شود؛ نیازی به سرور ندارد.

| | |
|---|---|
| حالت چهارنفره | یارگیری با آس، کوپ، پخش ۵–۴–۴، اعلام حکم با ۵ کارت اول، کوت و حاکم‌کوت (۲ و ۳ امتیاز)، چرخش حاکم/دیلر طبق قانون |
| حالت دونفره | پخش ۵+۵، دورریز ۳/۲، برگهٔ ۴۲تایی با قانون «نگه دار یا رد کن (دومی اجباری)» تا ۱۳ کارت، سپس دست‌ها |
| امتیاز | بردن دست = ۱ · کوت ۷–۰ = ۲ · حاکم‌کوت = ۳ · هدف بازی ۷ امتیاز |

ساختار
-------
```
index.html          شِل اپ (+ اسکریپت تلگرام و فونت وزیرمتن)
css/style.css       دیزاین‌سیستم، انیمیشن‌ها، RTL
js/cards.js         دادهٔ کارت، شافل سیددار، مرتب‌سازی
js/engine.js        موتور قانون (خالص، بدون DOM) — یارگیری، پخش، دست‌ها، امتیاز، چرخش نقش‌ها، فازهای دونفره
js/ai.js            مغز AI: انتخاب حکم، بازی کارت، دورریز، تصمیم برداشت
js/sound.js         افکت صوتی سینتی‌سایز‌شده (WebAudio، بدون فایل)
js/ui.js            ساخت DOM و انیمیشن‌ها (WAAPI)
js/app.js           چرخهٔ بازی، صفحه‌ها، اتصال تلگرام (Haptic، BackButton، تم، viewport)
tests/              تست موتور (۳۲۸ ادعا) + اسموک UI کامل با jsdom
```

اجرای محلی
----------
```bash
cd hokm-tma
python3 -m http.server 8080     # سپس http://localhost:8080
```
بیرون از تلگرام هم کار می‌کند (حالت دمو). تست‌ها:
```bash
npm install            # فقط jsdom برای تست UI
node tests/run-tests.js
node tests/smoke-ui.test.js
```

انتشار + اتصال به بات
---------------------
۱) پوشه را روی هر هاست استاتیک HTTPS منتشر کنید (GitHub Pages / Netlify / Vercel).
۲) در BotFather: `/newbot` یا بات خودتان → `/newapp` (یا Bot Settings › Menu Button) → آدرس `https://…/index.html` را بدهید.
۳) تمام.

نکتهٔ امنیتی: بازی تک‌نفره-آفلاین است و هیچ داده‌ای (از جمله initData) به سروری ارسال نمی‌شود؛ اگر بعداً بک‌اند افزودید، حتماً `initData` را سمت سرور با HMAC توکن بات اعتبارسنجی کنید.

بازی آنلاین چندنفره
-------------------
از منو → «آنلاین»:
* «ساخت بازی ۲ نفره / ۴ نفره» → اتاق با **کد ۶ حرفی** ساخته می‌شود.
* دکمهٔ «کپی لینک دعوت» لینکی مثل `https://<دامنه>/?room=CODE` می‌دهد؛ «دعوت در تلگرام» همان را در چت‌ها به اشتراک می‌گذارد. داخل تلگرام این شکل هم کار می‌کند: `https://t.me/<بات>/<اپ>?startapp=CODE`.
* دوستت لینک را باز کند یا کد را تایپ کند؛ اتاق که پر شد بازی خودکار شروع می‌شود. جای خالی را هم میزبان می‌تواند «شروع با ربات‌ها» بپوشاند.

قوانین جا‌ماندن / ربات‌جانشینی
-----------------------------
| وضعیت | اتفاق |
|---|---|
| قطع ناگهانی شبکه | ۳۰ ثانیه فرصت بازگشت؛ اتصال مجدد خودکارِ کلاینت فعال است؛ کارت‌ها دست‌نخورده برمی‌گردند و صندلی از ربات پس گرفته می‌شود |
| بعد از ۳۰ ثانیه | صندلی تا پایان مسابقه به ربات واگذار می‌شود (بازی نمی‌ایستد)؛ هر وقت برگشت، صندلیش آزاد است |
| خروج دکمه‌ای | بدون انتظار — فوری ربات جای او بازی می‌کند |
| کندی بیش از ۴۵ ثانیه برای هر حرکت | هشدار در ۱۵ ثانیه مانده (بنر + لرزش + شمارندهٔ قرمز)؛ پس از ۴۵ ثانیه ربات یک حرکت می‌کند و ۱ اخطار ثبت می‌شود |
| ۳ اخطار | تا پایان مسابقه صندلی به ربات سپرده می‌شود؛ روی صندلی نشان ⚠ ظاهر می‌شود |

اجرا کردن سرور محلی:
```bash
npm install && npm start        # ws-only dependency; http+ws on PORT (default 8080)
npm test                        # engine + UI smoke + room tests (server/leave system)
node tests/room.test.js         # ۱۳ تست مستقل سیستم خروج/ربات‌جانشینی
```

انتشار (Railway) + اتصال به بات
-------------------------------
1. پوشه را دیپلوی کنید (`railway up` یا متصل‌کردن ریپو؛ `start` = `node server.js`، فقط `ws` لازم است، پورت از `env.PORT`).
2. `/healthz` باید `ok` بدهد. WebSocket روی همان دامنه مسیر `/ws` است.
3. در BotFather: Bot Settings › Menu Button (یا `/newapp`) → آدرس `https://<دامنه>/` را ثبت کنید.
4. اگر آدرس مینی‌اپ `https://t.me/<bot>/<app>` باشد، لینک دعوت داخل تلگرام `https://t.me/<bot>/<app>?startapp=CODE` دوستتان را مستقیم به اتاق می‌برد.

محدودیت فعلی: اتاق‌ها در حافظهٔ سرورند — با ریستارت سرویس اتاق‌ها ریست می‌شوند (برای بازی دوستانه مشکلی نیست).


ربات تلگرام و دعوت واقعی
------------------------
بات @Echohokmbot به همین سرور وصله (webhook):
* «دعوت دوست» داخل بازی، لینک `https://t.me/Echohokmbot?start=room_CODE` را کپی می‌کند؛ لینک وب فقط جایگزین است.
* دوستت لینک را باز کند → بات پیام «دعوت به لابی» با دکمهٔ «ورود به لابی» می‌فرستد → مینی‌اپ با سؤال «ملحق می‌شوی؟» باز می‌شود.
* `/start` (بدون کد) منو، `/stats` آمار، `/help` راهنما.
* هر حساب تلگرام با `initData` امضا‌شده اعتبارسنجی می‌شود (HMAC)؛ نام و آمار هر حساب در دیتابیس ذخیره می‌شود (Postgres اگر `DATABASE_URL` باشد، وگرنه فایل پایدار روی والیوم/دیسک).
* تنظیمات حساس در `server/config.production.json` است (ریپو خصوصی). متغیرهای محیطی اولویت دارند: `BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `TELEGRAM_BOT_USERNAME`, `APP_PUBLIC_URL`, `DATABASE_URL`.
